List Agents

Beta
GET/v1/ai/agents

Returns all system and custom agent definitions for the current account.

status[]optional arrayenumValues: active, inactive

Filter by account-level status. Defaults to "active".

definition_type[]optional array

Filter by definition type (e.g. "system", "custom").

trigger_type[]optional array

Filter by trigger type (e.g. "manual", "scheduled", "event").

include[]optional arrayenumValues: config, tools, role,

Sub-objects to expand in the response. When omitted, sub-objects are returned as null.

objectstringenumValues: list

Object type for AgentDefinition list

page_infoobject

Pagination metadata for AgentDefinition list

next_cursorstringnullable

Cursor to fetch the next page of results, null if no more pages.

prev_cursorstringnullable

Cursor to fetch the previous page of results, null if on the first page.

has_next_pageboolean

Whether there are more results after this page.

has_prev_pageboolean

Whether there are results before this page.

dataarray of object

Array of AgentDefinition resources in this page

idstring

The unique identifier for the agent definition.

objectstringenumValues: agent_definition

The resource type identifier.

namestring

The display name of the agent.

slugstring

The unique slug identifier.

descriptionstringnullable

A description of what the agent does.

definition_typestringenumValues: system, custom

Agent definition type.

category_codestring

The category code for this agent.

trigger_typestringenumValues: scheduled, manual, event

How this agent is triggered.

is_editableboolean

Whether the current user can edit this agent definition.

roleobjectExpandablenullable

The role that defines this agent's permissions.

idstring

The unique identifier for the role.

objectstringenumValues: role

The resource type identifier.

namestring

The display name of the role.

role_type_codestringenumValues: admin, user, scanner,

The role type code.

is_internalboolean

Whether this role belongs to the account (true) or is a global system role (false).

permissionsarray of objectExpandable

The structured permissions for this role. Expandable.

idstring

The unique identifier for this role permission.

objectstringenumValues: role_permission

The resource type identifier.

permission_codestring

The permission domain code (e.g. "customers", "invoices").

createboolean

Whether this permission grants create access.

readboolean

Whether this permission grants read access.

updateboolean

Whether this permission grants update access.

deleteboolean

Whether this permission grants delete access.

created_atstring (date-time)

When this role permission was created.

updated_atstring (date-time)

When this role permission was last updated.

created_atstring (date-time)

The timestamp when the role was created.

updated_atstring (date-time)

The timestamp when the role was last updated.

configobjectExpandablenullable

The agent configuration.

objectstringenumValues: agent_definition_config

The resource type identifier.

system_promptstringnullable

The system prompt / instructions given to the agent.

modelstringnullable

The LLM model identifier (e.g. "claude-sonnet-4").

providerstringnullable

The LLM provider name (e.g. "anthropic", "openai"). Inferred from model if omitted.

temperaturenumbernullable

LLM sampling temperature between 0 and 1.

trigger_configobjectnullable

Trigger-specific configuration. Shape depends on the agent's trigger_type.

objectstringenumValues: trigger_config

The resource type identifier.

cron_schedulestringnullable

Cron expression for scheduled triggers (e.g. "0 9 * * *").

timezonestringnullable

IANA timezone for the cron schedule (e.g. "America/New_York").

event_filtersarray of string

Event types that trigger this agent (e.g. ["email.received", "order.created"]).

toolsarray of objectExpandable

The tools attached to this agent.

idstring

The unique identifier for this agent-tool link.

objectstringenumValues: agent_definition_tool

The resource type identifier.

toolobject

The tool attached to this agent definition.

idstring

The unique identifier for the tool.

objectstringenumValues: available_tool

The resource type identifier.

display_namestring

The display name of the tool.

descriptionstringnullable

A description of the tool.

config_schemaarray of object

A JSON schema describing what configuration options this tool accepts. Defines the shape of the config field on AgentDefinitionTool. For example: {"type":"object","properties":{"max_results":{"type":"integer","default":10}}}.

categorystring

The tool category.

required_permissionsarray of string

Permissions required to use this tool.

configarray of object

The instance-specific configuration values for this tool on this agent. Must conform to the tool's config_schema. These values are used by the tool handler at runtime but are not exposed to the LLM.

sort_orderinteger

The sort order of this tool within the agent.

require_reviewboolean

Whether this tool requires human review before execution.

statusstringenumValues: active, inactive

The per-account activation status for this agent definition.

created_atstring (date-time)

When this agent definition was created.

updated_atstring (date-time)

When this agent definition was last updated.
