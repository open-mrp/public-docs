The **order data** dashboard provides a flat, line-level view of every sales transaction. Unlike the visual charts in order analytics, this dashboard is designed for users who need to search, sort, filter, and export raw sales data.

### Why order data matters

- **Ad-hoc analysis**: sort and filter columns directly in the grid to answer questions without switching to a spreadsheet
- **Bulk export**: download the full data set as an Excel file for offline reporting or sharing with stakeholders
- **Transactional detail**: every order line is a row, giving you granular visibility into what was sold, to whom, and at what price

### What you'll see

A full-width data grid displaying all sales transactions for the selected date range. The grid includes a toolbar with built-in search, column visibility controls, and density options.

Each row represents an order line item with columns for order details, customer information, product details, quantities, and prices.

### Filters

| Field          | What it does                             |
| -------------- | ---------------------------------------- |
| **Date range** | Sets the period of sales data to display |

### Export

An **Export** button downloads the sales data as an Excel file.

### Role-based visibility

Sales reps see a filtered view scoped to their own sales, and the grid displays a different column layout tailored to the rep's perspective. The exported Excel file is also scoped to the rep's data.
