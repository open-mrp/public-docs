The **quarterly orders** dashboard plots order values by quarter so you can compare seasonal patterns and year-over-year growth in a single view.

### Why quarterly orders matters

- **Seasonal patterns**: see how order volumes shift across Q1 through Q4 each year
- **Year-over-year comparison**: multiple years are plotted on the same chart so growth or decline is immediately visible
- **Targeted analysis**: filter by product, product line, customer, or customer group to isolate specific segments

### What you'll see

A line chart spanning multiple years with data points at each quarter. Each year is rendered as its own series so you can compare the same quarter across years. Tooltips display the formatted date and currency value when you hover over a data point.

### Filters

| Field               | What it does                                                         |
| ------------------- | -------------------------------------------------------------------- |
| **Products**        | Limits data to selected products (searchable by SKU and description) |
| **Product lines**   | Limits data to selected product lines                                |
| **Customers**       | Limits data to selected customers                                    |
| **Customer groups** | Limits data to selected customer groups                              |
| **Sales reps**      | Limits data to selected sales reps                                   |

### Export

An **Export** button downloads the quarterly orders data as an Excel file.

### Role-based visibility

Sales reps cannot filter by sales rep. The filter is hidden for users with a sales rep role.
