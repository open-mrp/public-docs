The **manufacturing analytics** dashboard surfaces five key production KPIs. Each metric compares the current period against the prior period so you can quickly see whether performance is improving or declining.

### Why manufacturing analytics matters

- **Production tracking**: monitor how many units are being produced and whether output is growing
- **Cost control**: track cost per unit to catch rising material or labor costs early
- **Margin visibility**: see gross margin trends to ensure pricing keeps pace with costs
- **Quality monitoring**: measure quality rates to identify problems before they escalate
- **Labor efficiency**: evaluate how effectively labor hours translate into finished goods

### What you'll see

Five metric cards arranged in a responsive grid. Each card displays:

- The current-period value
- The comparison-period value
- A percent-change indicator (green for improvement, red for decline)

| Metric               | Format     | What it shows                           |
| -------------------- | ---------- | --------------------------------------- |
| **Production**       | Units      | Total units produced in the period      |
| **Costs per unit**   | Currency   | Average cost per unit produced          |
| **Margin**           | Percentage | Gross margin as a percentage of revenue |
| **Quality**          | Percentage | Quality rate across production runs     |
| **Labor efficiency** | Percentage | Output relative to labor hours invested |

### Filters

| Field                     | What it does                                                     |
| ------------------------- | ---------------------------------------------------------------- |
| **Date range**            | Sets the current analysis period                                 |
| **Comparison date range** | Sets the period to compare against (defaults to the prior month) |
| **Customers**             | Limits data to selected customers                                |
| **Customer groups**       | Limits data to selected customer groups                          |
| **Product lines**         | Limits data to selected product lines                            |
| **Sales reps**            | Limits data to selected sales reps                               |
