## Use Augno without writing code

The easiest way to get started with Augno is to use the <DocLink pathKey="frontend.dashboard">Augno Dashboard</DocLink>. This application is a complete solution for
most business needs and is the fastest way to get started.

Most businesses will be able to use this solution alone, and can utilize the developer tools to
extend the platform to their custom needs.

## Developer setup

We provide a comprehensive developer API that allows you to build custom integrations with Augno. In addition, we provide
an OpenAPI specification for the API that can be used to generate client libraries in your language of choice.

> #### Best Practices
>
> Mostly likely, you won't need to build a custom integration for every single aspect of your operation. Instead, we
> recommend that you only develop custom integrations when the specific functionality you need is **not available out of the box**.
>
> You should consider custom tools if you need to develop a unique workflow (e.g. CAD design ->
> quote -> order) or uncommon integrations with external systems.
