## The Unit resource

Unit represents a unit of measurement used for conversions and product quantities.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | Yes | The unique identifier for the unit. |
| `object` | string | Yes | The object type. Always `unit`. |
| `name` | string | Yes | The display name of the unit (e.g. "Gram", "Kilogram"). |
| `abbreviation` | string | Yes | The short abbreviation for the unit (e.g. "g", "kg"). |
| `type` | string | Yes | The unit dimension (e.g. "quantity", "mass", "time", "currency"). Values: `currency`, `quantity`, `time`, `mass`, `volume`, `length`, `temperature`, `area` |
| `ratio_numerator` | decimal | Yes | The conversion ratio numerator relative to the base unit in the same dimension. |
| `ratio_denominator` | decimal | Yes | The conversion ratio denominator relative to the base unit in the same dimension. |
| `offset_numerator` | decimal | Yes | The conversion offset numerator, used for temperature-like conversions. Zero for most unit types. |
| `offset_denominator` | decimal | Yes | The conversion offset denominator. Typically 1. |
| `is_base_unit` | boolean | Yes | Whether this unit is the base unit for its dimension. Conversion ratios are relative to this unit. |
| `is_internal` | boolean | Yes | Whether this unit belongs to the requesting account. False for system/global units. |
| `created_at` | datetime | Yes | When this unit was created. |
| `updated_at` | datetime | Yes | When this unit was last updated. |

## Endpoints

### List Units <span className="toc-hidden"><BetaTag /></span>

This endpoint returns a paginated list of units for the target account, including both account-specific and global system units.
Supports cursor-based pagination, filtering by dimension type and unit group membership, and search by name or abbreviation.

```http
GET /v1/core/units
```

#### Query Parameters<span className="hidden toc-hidden"> for List Units</span>

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `type` | string | No | Filter by unit dimension code (e.g. "mass", "quantity"). |
| `unit_group_ids` | array | No | Filter by unit group membership. |

#### Response<span className="hidden toc-hidden"> for List Units</span>

**`200`** Successful response for List Units

Returns a paginated list of [`Unit`](#the-unit-resource) objects. See [Pagination](/api/pagination) for envelope details.

### Create Unit <span className="toc-hidden"><BetaTag /></span>

This endpoint creates a new account-owned unit.

```http
POST /v1/core/units
```

#### Request Body<span className="hidden toc-hidden"> for Create Unit</span>

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | Yes | The display name of the unit (e.g. "Gram"). |
| `abbreviation` | string | Yes | The short abbreviation for the unit (e.g. "g"). |
| `type` | string | Yes | The unit dimension code (e.g. "mass", "quantity"). Values: `currency`, `quantity`, `time`, `mass`, `volume`, `length`, `temperature`, `area` |
| `ratio_numerator` | string | Yes | The conversion ratio numerator relative to the base unit, as a decimal string. |
| `ratio_denominator` | string | Yes | The conversion ratio denominator relative to the base unit, as a decimal string. |
| `offset_numerator` | string | Yes | The conversion offset numerator, as a decimal string. |
| `offset_denominator` | string | Yes | The conversion offset denominator, as a decimal string. |
| `is_base_unit` | boolean | Yes | Whether this unit is the base unit for its dimension. |

**Example:**

```json
{
  "name": "Gram",
  "abbreviation": "g",
  "type": "mass",
  "ratio_numerator": "1.000000000000000000000000000000",
  "ratio_denominator": "1.000000000000000000000000000000",
  "offset_numerator": "0.000000000000000000000000000000",
  "offset_denominator": "1.000000000000000000000000000000",
  "is_base_unit": true
}
```

#### Response<span className="hidden toc-hidden"> for Create Unit</span>

Returns a [`Unit`](#the-unit-resource) object.

**Example:**

### Update Unit <span className="toc-hidden"><BetaTag /></span>

This endpoint partially updates an account-owned unit.
Only provided fields are updated; absent fields retain their current values.
System units cannot be updated.

```http
PATCH /v1/core/units/{id}
```

#### Path Parameters<span className="hidden toc-hidden"> for Update Unit</span>

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `id` | string | Yes | The ID of the unit to update. |

#### Request Body<span className="hidden toc-hidden"> for Update Unit</span>

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string, nullable | No | The display name of the unit. |
| `abbreviation` | string, nullable | No | The short abbreviation for the unit. |
| `ratio_numerator` | string, nullable | No | The conversion ratio numerator, as a decimal string. |
| `ratio_denominator` | string, nullable | No | The conversion ratio denominator, as a decimal string. |
| `offset_numerator` | string, nullable | No | The conversion offset numerator, as a decimal string. |
| `offset_denominator` | string, nullable | No | The conversion offset denominator, as a decimal string. |

### Delete Unit <span className="toc-hidden"><BetaTag /></span>

This endpoint deletes an account-owned unit.
Associated unit group memberships are also removed. System units cannot be deleted.

```http
DELETE /v1/core/units/{id}
```

#### Path Parameters<span className="hidden toc-hidden"> for Delete Unit</span>

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `id` | string | Yes | The ID of the unit to delete. |

#### Response<span className="hidden toc-hidden"> for Delete Unit</span>

**`204`** Successful response for Delete Unit

**Example:**

```json
{}
```
