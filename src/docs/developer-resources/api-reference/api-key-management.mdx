## The APIKey resource

APIKey represents an API key for authenticating API requests.

| Field | Type | Nullable | Required | Description |
|-------|------|----------|----------|-------------|
| `id` | string | No | Yes | The unique identifier for the API key. |
| `object` | string | No | Yes | The resource type identifier. Always `api_key`. |
| `name` | string | No | Yes | The human-readable name for the API key. |
| `redacted_value` | string | No | Yes | The redacted value of the API key for display purposes. |
| `role` | [`LightRole`](#the-lightrole-object-lightrole) | Yes | Yes | The role associated with this API key. Expandable. |
| `created_at` | datetime | No | Yes | The timestamp when the API key was created. |
| `updated_at` | datetime | No | Yes | The timestamp when the API key was last updated. |
| `last_used_at` | datetime | Yes | Yes | The timestamp when the API key was last used. |
| `expires_at` | datetime | Yes | Yes | The timestamp when the API key expires. |
| `revoked_at` | datetime | Yes | Yes | The timestamp when the API key was revoked. |

### Example<span className="hidden toc-hidden"> of APIKey</span>

```json
{
  "id": "apke_01jm4r6700e3kxb9w2nqh7g5fp",
  "object": "api_key",
  "name": "Production API Key",
  "redacted_value": "aug_sk_prod_...hjt4",
  "role": {
    "id": "rl_01gf7a8200er3ar3pkfrb6kk29",
    "object": "role",
    "name": "Admin",
    "role_type_code": "admin"
  },
  "created_at": "2026-05-10T00:00:00Z",
  "updated_at": "2026-05-10T00:23:00Z",
  "last_used_at": "2026-05-10T00:23:00Z",
  "expires_at": "2026-06-10T00:00:00Z",
  "revoked_at": null
}
```

### The LightRole object<span className="hidden toc-hidden"> (lightrole)</span>

LightRole represents a minimal role reference.

| Field | Type | Nullable | Required | Description |
|-------|------|----------|----------|-------------|
| `id` | string | No | Yes | The unique identifier for the role. |
| `object` | string | No | Yes | The resource type identifier. Always `role`. |
| `name` | string | No | Yes | The display name of the role. |
| `role_type_code` | string | No | Yes | The role type code. Values: `admin`, `user`, `scanner`, `sales_rep` |

#### Example<span className="hidden toc-hidden"> of LightRole</span>

```json
{
  "id": "rl_01gf7a8200er3ar3pkfrb6kk29",
  "object": "role",
  "name": "Admin",
  "role_type_code": "admin"
}
```

## Endpoints

### List API Keys <span className="toc-hidden"><BetaTag /></span>

This endpoint returns a paginated list of API keys for the target account.
Supports cursor-based pagination and optional search filtering by name.

```http
GET /v1/auth/api-keys
```

#### Query Parameters<span className="hidden toc-hidden"> for List API Keys</span>

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `status` | array | No | Filter API keys by status. Values: `active`, `expired`, `revoked` |
| `include[]` | array | No | Sub-objects to expand in the response. When omitted, sub-objects are returned as `null`. Values: `role` |

#### Response<span className="hidden toc-hidden"> for List API Keys</span>

**`200`** Successful response for List API Keys

Returns a paginated list of [`APIKey`](#the-apikey-resource) objects. See [Pagination](/api/pagination) for envelope details.

### Create API Key <span className="toc-hidden"><BetaTag /></span>

This endpoint is used to create an API key. Once completed, the API key object is
returned, and the API key secret is returned. The secret is only returned once at creation, and is not retrievable after creation.

```http
POST /v1/auth/api-keys
```

#### Query Parameters<span className="hidden toc-hidden"> for Create API Key</span>

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `include[]` | array | No | Sub-objects to expand in the response. When omitted, sub-objects are returned as `null`. Values: `role` |

#### Request Body<span className="hidden toc-hidden"> for Create API Key</span>

| Field | Type | Nullable | Required | Description |
|-------|------|----------|----------|-------------|
| `role_id` | string | No | Yes | The role ID for the API key. |
| `name` | string | No | Yes | The name for the API key. |
| `expires_at` | datetime | Yes | No | Optional expiration time for the API key. |

**Example:**

```json
{
  "role_id": "rl_01gf7a8200er3ar3pkfrb6kk29",
  "name": "Production API Key"
}
```

#### Response<span className="hidden toc-hidden"> for Create API Key</span>

**`201`** Successful response for Create API Key

Returns a `CreatedAPIKey` object.

**Example:**

### Revoke API Key <span className="toc-hidden"><BetaTag /></span>

This endpoint revokes an API key so it can no longer be used to 
authenticate requests. The API key will be marked as revoked and will no longer be usable.

```http
DELETE /v1/auth/api-keys/{id}
```

#### Path Parameters<span className="hidden toc-hidden"> for Revoke API Key</span>

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `id` | string | Yes | The ID of the API key to revoke. |

#### Response<span className="hidden toc-hidden"> for Revoke API Key</span>

**`200`** Successful response for Revoke API Key

**Example:**

```json
{}
```

### Rotate API Key <span className="toc-hidden"><BetaTag /></span>

This endpoint rotates an API key by revoking the existing key and creating a new
replacement with the same name, role, and owner. The new key inherits the old key's expiration unless an explicit expires_at override is provided.
The new API key secret is returned once and is not retrievable after creation.

```http
POST /v1/auth/api-keys/{id}/actions/rotate
```

#### Path Parameters<span className="hidden toc-hidden"> for Rotate API Key</span>

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `id` | string | Yes | The unique identifier for the API key to rotate. |

#### Query Parameters<span className="hidden toc-hidden"> for Rotate API Key</span>

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `include[]` | array | No | Sub-objects to expand in the response. When omitted, sub-objects are returned as `null`. Values: `role` |

#### Request Body<span className="hidden toc-hidden"> for Rotate API Key</span>

| Field | Type | Nullable | Required | Description |
|-------|------|----------|----------|-------------|
| `expires_at` | datetime | Yes | No | Optional expiration time override for the new API key. |

**Example:**

```json
{
  "expires_at": "2026-12-31T23:59:59Z"
}
```
