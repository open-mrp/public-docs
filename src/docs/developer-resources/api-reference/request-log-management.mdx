## The RequestLog resource

RequestLog represents a single API request log entry.

| Field | Type | Nullable | Required | Description |
|-------|------|----------|----------|-------------|
| `id` | string | No | Yes | The unique identifier for the request log. |
| `object` | string | No | Yes | The resource type identifier. Always `request_log`. |
| `method` | string | No | Yes | The HTTP method. |
| `host` | string | No | Yes | The request host. |
| `path` | string | No | Yes | The request path. |
| `normalized_route` | string | No | Yes | The normalized route pattern. |
| `query_json` | string | Yes | Yes | The query parameters as JSON. |
| `status_code` | integer | No | Yes | The HTTP status code. |
| `latency_us` | integer | No | Yes | The request latency in microseconds. |
| `api_version` | string | Yes | Yes | The API version used. |
| `identity_type` | string | Yes | Yes | The identity type of the caller. |
| `client_ip` | string | Yes | Yes | The client IP address. |
| `user_agent` | string | Yes | Yes | The user agent string. |
| `referrer` | string | Yes | Yes | The referrer header. |
| `error_code` | string | Yes | Yes | The API error code, if any. |
| `error_message` | string | Yes | Yes | The error message, if any. |
| `occurred_at` | datetime | No | Yes | When the request occurred. |
| `created_at` | datetime | No | Yes | When the log entry was created. |
| `account` | [`LightAccount`](#the-lightaccount-object-lightaccount) | Yes | Yes | The account targeted by the request. Expandable. |
| `actor` | [`RequestLogActor`](#the-requestlogactor-object-requestlogactor) | Yes | Yes | Actor details (user or API key). Expandable. |
| `idempotency_key` | string | Yes | Yes | The user-provided idempotency key value. |
| `request_body_json` | string | Yes | Yes | The JSON request body. |
| `response_body_json` | string | Yes | Yes | The JSON response body. |

### The RequestLogActor object<span className="hidden toc-hidden"> (requestlogactor)</span>

RequestLogActor contains the resolved actor details for a request log.

| Field | Type | Nullable | Required | Description |
|-------|------|----------|----------|-------------|
| `id` | string | No | Yes | The actor's ID (user ID or API key type_id). |
| `object` | string | No | Yes | The resource type identifier. Always `user`. |
| `name` | string | Yes | Yes | The actor's display name. |
| `email` | string | Yes | Yes | The actor's email (users only). |
| `redacted_value` | string | Yes | Yes | The redacted API key value (API keys only). |
| `role` | [`LightRole`](#the-lightrole-object-lightrole) | Yes | Yes | The role assigned to the actor. Expandable. |

### The LightRole object<span className="hidden toc-hidden"> (lightrole)</span>

LightRole represents a minimal role reference.

| Field | Type | Nullable | Required | Description |
|-------|------|----------|----------|-------------|
| `id` | string | No | Yes | The unique identifier for the role. |

| `name` | string | No | Yes | The display name of the role. |
| `role_type_code` | string | No | Yes | The role type code. Values: `admin`, `user`, `scanner`, `sales_rep` |

## Endpoints

### List Request Logs <span className="toc-hidden"><BetaTag /></span>

This endpoint returns a paginated, filterable list of request logs for the target account.
Supports cursor-based pagination and various filters.

```http
GET /v1/core/request-logs
```

#### Query Parameters<span className="hidden toc-hidden"> for List Request Logs</span>

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `cursor` | string | No | Cursor for fetching the next page, from a previous response's next_cursor field. |
| `limit` | integer | No | Maximum number of results to return per page (default: 100, max: 1000). |
| `q` | string | No | Search query: matches against ID (exact), path (partial), or error message (partial). |
| `start_date` | string | No | Filter: start of date range for occurred_at. |
| `end_date` | string | No | Filter: end of date range for occurred_at. |
| `method` | string | No | Filter: HTTP method. |
| `status_code` | integer | No | Filter: HTTP status code. |
| `error_code` | string | No | Filter: API error code. |
| `account_id` | string | No | Filter: actor's home account ID. |
| `actor_id` | string | No | Filter: actor ID. |
| `actor_type` | string | No | Filter: actor type ("user" or "api_key"). |
| `actor_name` | string | No | Filter: actor name (partial or exact match). |
| `exact_match` | boolean | No | When true, string filters use exact match instead of partial (LIKE). |
| `include[]` | array | No | Sub-objects to expand in the response. When omitted, sub-objects are returned as `null`. Values: `account`, `actor`, `actor.role` |

#### Response<span className="hidden toc-hidden"> for List Request Logs</span>

**`200`** Successful response for List Request Logs

Returns a paginated list of [`RequestLogListItem`](#the-requestloglistitem-object-requestloglistitem) objects. See [Pagination](/api/pagination) for envelope details.
