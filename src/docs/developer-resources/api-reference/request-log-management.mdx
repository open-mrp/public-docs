## The RequestLog resource

RequestLog represents a single API request log entry.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | Yes | The unique identifier for the request log. |
| `object` | string | Yes | The object type. Always `request_log`. |
| `method` | string | Yes | The HTTP method. |
| `host` | string | Yes | The request host. |
| `path` | string | Yes | The request path. |
| `normalized_route` | string | Yes | The normalized route pattern with path parameters replaced by placeholders (e.g., `/v1/core/sandboxes/{id}`). |
| `query_json` | string, nullable | Yes | The query parameters as JSON. |
| `status_code` | integer | Yes | The HTTP status code. |
| `latency_us` | integer | Yes | The request latency in microseconds. Divide by 1,000 for milliseconds. |
| `api_version` | string, nullable | Yes | The API version used. |
| `identity_type` | string, nullable | Yes | The identity type of the caller. Possible values: `user`, `api_key`. |
| `client_ip` | string, nullable | Yes | The client IP address. |
| `user_agent` | string, nullable | Yes | The user agent string. |
| `referrer` | string, nullable | Yes | The referrer header. |
| `error_code` | string, nullable | Yes | The API error code, if any. |
| `error_message` | string, nullable | Yes | The error message, if any. |
| `occurred_at` | datetime | Yes | When the request occurred. |
| `created_at` | datetime | Yes | When the log entry was created. |
| `account` | [`LightAccount`](#the-lightaccount-object), nullable | Yes | The account targeted by the request. |
| `actor` | [`RequestLogActor`](#the-requestlogactor-object), nullable | Yes | Actor details (user or API key). |
| `idempotency_key` | string, nullable | Yes | The user-provided idempotency key value. |
| `request_body_json` | string, nullable | Yes | The JSON request body. Truncated at 256 KB. Null for security-sensitive endpoints (e.g., API key creation). |
| `response_body_json` | string, nullable | Yes | The JSON response body. Truncated at 256 KB. Null for security-sensitive endpoints (e.g., API key creation). |

### The LightAccount object<span className="hidden toc-hidden"> (lightaccount)</span>

LightAccount represents a minimal account reference.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | Yes | The unique identifier for the account. |
| `object_type` | string | Yes | The resource type identifier. Always `account`. |
| `name` | string | Yes | The display name of the account. |

#### Example<span className="hidden toc-hidden"> of LightAccount</span>

```json
{
  "id": "ac_01gf7a8200eaj8fke1xvw4h50x",
  "object_type": "account",
  "name": "Acme Inc."
}
```

### The RequestLogActor object<span className="hidden toc-hidden"> (requestlogactor)</span>

RequestLogActor contains the resolved actor details for a request log.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | Yes | The actor's ID (user ID or API key type_id). |
| `object_type` | string | Yes | The resource type identifier. Always `user`. |
| `name` | string, nullable | Yes | The actor's display name. |
| `email` | string, nullable | Yes | The actor's email (users only). |
| `redacted_value` | string, nullable | Yes | The redacted API key value (API keys only). |
| `role` | [`LightRole`](#the-lightrole-object), nullable | Yes | The role assigned to the actor. |

#### Example<span className="hidden toc-hidden"> of RequestLogActor</span>

```json
{
  "id": "usr_01hk5p9200abc123def456gh",
  "object_type": "user",
  "name": "Jane Smith",
  "email": "jane@example.com",
  "redacted_value": null,
  "role": {
    "id": "rl_01gf7a8200er3ar3pkfrb6kk29",
    "object_type": "role",
    "name": "Admin",
    "role_type_code": "admin"
  }
}
```

## Endpoints

### List Request Logs <span className="toc-hidden"><BetaTag /></span>

This endpoint returns a paginated, filterable list of request logs for the target account.
Supports cursor-based pagination and various filters.

```http
GET /v1/core/request-logs
```

#### Query Parameters<span className="hidden toc-hidden"> for List Request Logs</span>

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `cursor` | string | No | Cursor for fetching the next page, from a previous response's next_cursor field. |
| `limit` | integer | No | Maximum number of results to return per page (default: 100, max: 1000). |
| `q` | string | No | Search query: matches against ID (exact), path (partial), or error message (partial). |
| `start_date` | string | No | Filter: start of date range for occurred_at. |
| `end_date` | string | No | Filter: end of date range for occurred_at. |
| `method` | string | No | Filter: HTTP method. |
| `status_code` | integer | No | Filter: HTTP status code. |
| `error_code` | string | No | Filter: API error code. |
| `account_id` | string | No | Filter: actor's home account ID. |
| `actor_id` | string | No | Filter: actor ID. |
| `actor_type` | string | No | Filter: actor type ("user" or "api_key"). |
| `actor_name` | string | No | Filter: actor name (partial or exact match). |
| `exact_match` | boolean | No | When true, string filters use exact match instead of partial (LIKE). |

#### Response<span className="hidden toc-hidden"> for List Request Logs</span>

**`200`** Successful response for List Request Logs

Returns a paginated list of [`RequestLog`](#the-requestlog-resource) objects. See [Pagination](/api/pagination) for envelope details.

This endpoint returns a single request log by its ID.
