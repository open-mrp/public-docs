## Use Augno without writing code

The easiest way to get started with Augno is to use the <DocLink pathKey="frontend.root">Augno Dashboard</DocLink>. The Dashboard is a web application that acts as a frontend for the Augno API. This application is a complete solution for most business needs and is the fastest way to get started.

## Developer setup

We provide a comprehensive developer API that allows you to build custom integrations with Augno. We also provide some SDKs and an OpenAPI specification for the API that can be used to generate client libraries in your language of choice.

> #### Best Practices
>
> Mostly likely, you won't need to build a custom integration for every single aspect of your operation. Instead, we
> recommend that you only develop custom integrations when the specific functionality you need is **not available out of the box**.
>
> You should consider custom tools if you need to develop a unique workflow (e.g. CAD design ->
> quote -> order) or uncommon integrations with external systems.
