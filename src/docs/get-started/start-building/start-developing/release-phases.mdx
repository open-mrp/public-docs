We break down our releases into distinct phases. This allows us to set expectations on the availability of our product features and provides us with space to improve our products and API shape while soliciting feedback. Use the table below to learn more about each phase and what to expect.

| Product Release Phase         | Changes                                                                                                                                                           | Documentation                                                                                                                                                | Feature Completeness                                                                                                                   |
| :---------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------- |
| **Private Preview**           | Breaking changes may be expected over time as we update and develop functionality.                                                                                | Provided directly by the OpenMRP product team and potentially supplemented by early-access sections in the main OpenMRP documentation site.                      | Expect incompleteness and some limited functionality as we continue development and build the product in partnership with early users. |
| **Public Preview**            | Some breaking changes may be expected as we develop and update functionality based on broader feedback.                                                           | Available from the official OpenMRP documentation site and support pages. Features in public preview are marked with the <BetaTag /> tag in our documentation. | Not feature-complete and might include major new functionality or changes before full release.                                         |
| **General Availability (GA)** | No breaking changes expected for the current API version; any future breaking changes are typically handled through API version upgrades or new feature versions. | Comprehensive documentation available from the official OpenMRP documentation site and support pages.                                                          | Feature-complete.                                                                                                                      |

Products or features that you have access to in a preview phase are subject to terms and conditions applicable to Private Preview, Public Preview, or General Availability (GA) phases.
